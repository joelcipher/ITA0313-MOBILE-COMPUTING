MOBILE COMPUTING ASSIGNMENT 4 (CO4) — CODING PACK
=================================================
This pack follows Assignment 4B / Part II, Tasks 1–6.

IMPORTANT:
- Assignment 4A / Part I explicitly says it is a design-only exercise and that an IDE,
  emulator or SDK is not required. Therefore source code is not required for Part I.
- Assignment 4B / Part II requires implementation/instrumentation. The files here are
  starter/reference implementations for the coding and evidence portions.
- Run only on your own test device/emulator and your own test app.
- Do not submit simulated values as measured device results. Record actual output from
  your own runs and replace illustrative energy coefficients with measurements.
- Android APIs and adb subcommands vary by OS/API level. Check availability on your build.

Folder map:
task1/android_lifecycle/      Kotlin lifecycle logger + adb commands
task2/                        Python benchmark + Kotlin threading pattern
task3/                        Kotlin ART/runtime benchmark + commands
task4/                        Python Android manifest security auditor + sample manifest
task5/                        Kotlin WorkManager power-aware worker + measurement commands
task6/                        Python battery-aware tracking policy simulation

Suggested use:
1. Start with README in each task folder.
2. Run the Python scripts with Python 3.10+.
3. Paste Kotlin snippets into a small Android test project, adding the listed dependencies.
4. Capture screenshots/logs from your actual emulator/device.
